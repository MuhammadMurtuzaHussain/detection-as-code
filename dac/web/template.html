      How this page is made

      1. Rules are Sigma YAML files in rules/. Each one has a folder of malicious and benign JSON logs in tests/cases/.
      2. On every push, CI lints the rules, runs each rule against all logs, and checks that the JavaScript engine on this page returns the same verdicts as the Python engine.
      3. When everything passes on the main branch, CI rebuilds this page and publishes it.

      The logs are synthetic. A pass shows that each rule does what its author intended on these samples. It does not show that the rule catches every real attack or stays quiet in your environment.
